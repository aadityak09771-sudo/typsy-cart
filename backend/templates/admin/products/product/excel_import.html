📊 Method 1: Excel Spreadsheet (.xlsx)

  • Ideal when images are hosted online via URLs (HTTP/HTTPS) or products don't have new local image files.
  • Put direct image URLs in the Main Image and Gallery Images columns.
  • Fastest way to update prices, stock, MRP, and descriptions in bulk.

📦 Method 2: ZIP Package (.zip + Images)

  • Put your Excel file and product image files (e.g. fish_rohu.jpg, atta.png) into a folder.
  • Compress the folder into a .zip archive and upload it below.
  • Images matching the filenames will automatically upload to Cloudinary and attach to products and variants!

📋 Smart Features & Format Specifications

  • Automatic Category Creation: Products are automatically placed into the specified Category and Subcategory. If they don't exist yet, TipsyCart creates them automatically with clean SEO slugs.
  • Variable Products (Weights & Sizes): For products like Fish or Staples with multiple weights (e.g. 250g, 500g, 1 kg), create consecutive rows with the same Product Name and different Variant Name (Size / Weight), Variant Price, and Variant Stock.
  • Safe Update vs. Create: If a row's SKU or Product Name matches an existing product, it safely updates its pricing, stock, and info without breaking order history. If it is new, it creates a fresh product.
  • Homepage Speed: The homepage cache is automatically purged upon import completion so new items appear immediately for shoppers.
